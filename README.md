# アナハイム・エレクトロニクス 非公式ホームページ

「機動戦士ガンダム」シリーズに登場する架空企業、アナハイム・エレクトロニクスの企業サイト風ファンメイドページです。

- `index.html` … ページ本体（企業情報・事業紹介・製品・沿革・ニュース・採用・お問い合わせ）
- `style.css` … スタイル（レスポンシブ対応）
- `script.js` … 星空アニメーション、製品フィルター、モバイルメニュー、フォーム検証（送信はデモ）

ビルド不要です。`index.html` をブラウザで開くか、GitHub Pages で公開できます。

※本サイトは非公式のファンメイドであり、株式会社サンライズ（バンダイナムコフィルムワークス）および関連各社とは関係ありません。
